# DAC-3D AI 高速瑕疵检测方案 —— 达成指标(5)(6)(8) V1.0

> 对应考核指标：
> - **(5)(6)** 平板/小角锲角片类透镜（表面颗粒、麻点、划痕、崩边）检测效率 **≥ 人工 5 倍**
> - **(8)** 小角锲角片表面瑕疵 **敏感性 ≥ 99%、特异性 ≥ 90%**
>
> 技术栈：Windows + NVIDIA GPU + TensorRT + Ultralytics YOLO11 + 两级架构 + **3D 高度融合**。
> 配套文档：[`architecture.md`](./architecture.md)、[`dataset-management-guide.md`](./dataset-management-guide.md)、[`dac3d-product-strategy.md`](./dac3d-product-strategy.md)。

---

## 0. 一句话方案

> 单视场 2048×2048 图**原分辨率切片（tiling）**喂 YOLO11（+P2 小目标头，INT8）→ 一级低阈值"宁可错杀"把**敏感性**拉到 99.5%+ → 用**三维闪测的 Z 高度图**物理校验候选框（灰尘在表面之上、瑕疵在表面之下，符号相反）+ 轻量二级分类器 → 把**特异性**拉回 90%+。检测后端做成**可换接口**，配方驱动，与现有 `DefectService` 并列。

---

## 1. 先把吞吐算清楚（决定选型，别买贵了）

已知：相机 2048×2048（4.19 MP），一件一视场；XY 分辨 0.2µm/px；最小瑕疵 1.35µm；节拍 0.8s/件、144 件。

| 量 | 计算 | 结果 |
|----|------|------|
| 单视场物理尺寸 | 2048 × 0.2µm | ≈ 410 × 410 µm |
| 最小瑕疵像素 | 1.35µm ÷ 0.2µm/px | **≈ 7 px** |
| 切片数/件 | 640 切片、15% overlap（stride 544）：⌈(2048−640)/544⌉+1=4，4×4 | **16 片/件**（1024 切片则 9 片）|
| 推理耗时/件 | 16 片 @ RTX 4060 Ti 16G(~1000 tiles/s) | **~16 ms**（4090 约 5 ms）|
| 二级分类 | 每件几~几十个候选 crop × <0.5ms | 几 ms |
| **推理段合计/件** | | **~20–40 ms** |

**关键结论：**
1. **瑕疵只有 ~7px → 切片必须在原图上裁剪（不缩放）。** 若把 2048 整图缩到 640，瑕疵只剩 ~2px 会丢——这是切片的根本原因。P2 小目标头进一步救 2–7px 区间。
2. **在 0.8s/件节拍下，推理段仅占 3–5%，RTX 4060 Ti 16G 已足够。** 4090/A6000 只在节拍 <0.1s 或多相机并检时才必要。**钱别砸在推理 GPU 上。**
3. **真正的瓶颈在别处：三维闪测的 3D 重建。** 指标(4)要求 >10M 点/s，而一个 4.19M 点的视场 ≈ **0.42s** 就花在 3D 采集/重建上——占了半个节拍。**所以 2D-AI 推理要与 3D 重建并发流水**（2D 在 GPU、3D 在其专用通道，重叠执行），而不是串行等待。用 Nsight Systems 抓一次全链路时序，确认 2D/3D/运动/落盘的重叠度。

## 2. 敏感性 99% + 特异性 90% 的三级防线

### 防线一：YOLO 一级 —— 管"宁可错杀"（保敏感性）
- Ultralytics YOLO11s/m + **P2 小目标检测头**；置信度阈值压低（0.15–0.25），敏感性拉到 99.5%+，误报暂时多——这是设计意图。
- **按类别分别设阈值**：崩边和麻点的置信度分布完全不同（`DetectorConfig.conf_by_class`）。

### 防线二：3D 高度融合 —— 管"物理去伪"（保特异性，本方案核心增量）
用三维闪测免费得到的 Z 高度图，对每个候选框做符号校验：

| 目标 | Z 高度签名 | 判定 |
|------|-----------|------|
| 麻点 / 划痕 | 低于局部表面（**−Z 凹陷**） | 真瑕疵，保留并加权 |
| 崩边 | 边缘处深度突变（Z 方差大） | 真瑕疵，保留 |
| 嵌入颗粒 | 有亚表面结构 | 真瑕疵 |
| **灰尘 / 污渍 / 反光伪影** | 浮于表面**上方（+Z 凸起）**、无嵌入深度 | **判为污染，剔除** |

- 环境使用条件已明确要求"灰尘少"（指标4使用条件1）——说明**灰尘误报是已知痛点**，这一级就是解它的。
- 这是纯 2D 竞品**做不到**的物理判据，把"三维闪测"的差异化直接变成特异性武器。
- 附带增益：部分 2D 弱对比浅坑在 Z 图上清晰 → 2D∪3D 取并集**同时抬高敏感性**。
- 实现见 `dac3d/services/ai_detection/fusion.py::HeightFusion`。

### 防线三：轻量二级分类器 —— 管"纹理去伪"（补 3D 够不着的）
- 一级检出的候选 crop 过 ResNet18/MobileNet（INT8 后单 crop <0.5ms），区分真瑕疵 vs 反光/水渍等**无高度签名**的 2D 伪影。
- 与防线二互补：3D 管"有没有高度异常"，二级管"纹理像不像真瑕疵"。

配套闭环：**难例回流**——产线人工复判的漏报/误报自动回流训练集，每 2–4 周迭代一版；验收统计量足够（验证 99% 敏感性，缺陷样本 ≥300 例，见第 5 节）。

## 3. 落到项目代码：可换检测后端（与 HAL 同哲学）

检测后端做成**可换接口**，配方选择——延续本项目"接口+实现分离、配方驱动、设备无关"的架构底线（换算法后端不改上层）：

```
dac3d/services/ai_detection/
├── interface.py       IDefectDetector 接口 + DefectResult/DefectCandidate/DetectorConfig/DefectClass
├── tiling.py          Tiler：原分辨率切片 + 跨片全局 NMS 合并
├── fusion.py          HeightFusion：Z 高度图物理去伪(灰尘剔除，本方案核心)
├── sim_detector.py    SimDefectDetector：无 GPU 可跑，SIL/单测用
└── yolo_trt_detector.py  YoloTrtDetector：Windows+TensorRT 生产实现(骨架)
```

- **接口 `IDefectDetector.detect(image, z_map=None) -> DefectResult`**：现有传统 CV `DefectService` 可视为一个后端；`YoloTrtDetector` 是生产后端；`SimDefectDetector` 是仿真后端。三者可被配方 `recipe` 选择切换。
- 复用现有 `DefectInfo`/瑕疵概念，不另起炉灶。
- **配方驱动**：`DetectorConfig`（切片尺寸、每类阈值、3D 融合开关、灰尘高度阈值）全部写进配方，换零件类型（平板 vs 锲角片）只改配方。

### Windows 生产推理栈（三层保障，落在 `yolo_trt_detector.py`）
- **模型侧**：`model.export(format="engine", half=True, int8=True, batch=16)` 生成 TensorRT engine；INT8 用 500–1000 张产线图校准，量化后**必须在验证集重标定阈值**（因有 99% 敏感性红线）。
- **流水线侧**：三段异步（取流/切片 → 推理 → NMS/合并/判定）+ CUDA Streams 重叠 H2D/kernel/D2H；预处理上 GPU（NPP/CV-CUDA，勿用 CPU OpenCV 切片）；pinned memory + `cudaMemcpyAsync`；切片天然成 batch(16–32) 喂 engine。
- **系统侧**：专业卡开 TCC / GeForce 开"硬件加速 GPU 计划"；电源高性能、锁 GPU 频率(`nvidia-smi -lgc`)。
- 产线程序建议 C++（TensorRT C++ API）或 C#界面+C++ DLL；Python 侧本骨架用于训练/验证/SIL 与算法迭代，生产热路径按需转 C++。

## 4. 崩边（chip）—— 2D+3D 双确认
崩边在深度图上是**硬信号**（边缘深度突变）。做法：YOLO 检边缘区 ROI + Z 向点云的深度不连续双确认，敏感性/特异性同时受益，正好呼应"三维闪测"卖点。见 `fusion.py` 对 `CHIP` 类的方差判据。

---

## 5. 落地顺序与验收
1. 200–500 张标注图训 YOLO11s baseline（PyTorch），验证敏感性可达性 → 决定要不要 P2 头/更大切片。
2. 导出 TensorRT INT8，标定**双阈值**（一级低阈 + 二级/3D 去伪）。
3. C++ 流水线集成，Nsight 找瓶颈（预期瓶颈是 3D 重建与运动，非推理）。
4. 加二级分类器 + 3D 高度融合 + 难例回流。
5. 产线连续 batch 统计验收：**敏感性 ≥99%（缺陷样本 ≥300 例以压住置信区间）、特异性 ≥90%、节拍达标即效率 ≥人工 5 倍**。

## 6. 与指标的对应
| 指标 | 本方案如何达成 |
|------|---------------|
| (5)(6) 效率≥人工5倍 | 单件推理 20–40ms，节拍瓶颈在 3D/运动；2D-AI 与 3D 并发流水 |
| (8) 敏感性≥99% | 一级低阈"宁可错杀" + 2D∪3D 并集 |
| (8) 特异性≥90% | **3D 高度融合剔灰尘** + 二级分类器"去伪存真" |
| (7) 面型 / 崩边 | 崩边 2D+3D 双确认；面型走 Z 点云 |

---

*本方案的 2D-AI 部分负责表面瑕疵(5)(6)(8)；三维形貌/面型(1)-(4)(7)由三维闪测光学与 Z 通道负责，二者在决策层融合。骨架代码见 `dac3d/services/ai_detection/`。*
