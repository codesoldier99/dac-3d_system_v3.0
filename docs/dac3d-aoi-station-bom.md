## 0. 先解决"为什么重复性不够"——这不是买贵设备能解决的

样机的三大痛点有明确的技术根因，改造要对症，而不是堆料：

| 痛点 | 根因 | 硬件对策(本 BOM 的重点) |
|------|------|------------------------|
| **线太乱** | 各设备各自拉线、无集中、无屏蔽/标号 | 用 **DAC-3D 控制器**集中，后面板 DB25/SMA/GX12 连接器化，屏蔽双绞 + 线号 |
| **控制分散** | 多台上位机/多段脚本各管一摊，时序靠软件 | **一台 DAC-3D 控制器统一**，FPGA 硬件同步，一套软件 + 配方 |
| **重复性不够** | ①软件触发抖动 ②旋转编码器/丝杠背隙 ③热漂移/振动 ④无溯源标定 ⑤曝光时刻不定 | ①FPGA 几十纳秒硬触发 ②直线电机+光栅尺 ③隔振+恒温+预热 ④标准台阶片定期标定 ⑤FPGA 门控频闪定义曝光 |

> **重复性 = 系统工程**，五个根因同时压住才有效。本 BOM 把钱优先投在这五处，而非最贵的相机/物镜。

## 3. 线阵 vs 面阵相机：都上，各司其职

你要求补上线阵相机，非常对——AOI 三维里两者互补：

| | 面阵相机 | 线阵相机 |
|---|---------|---------|
| 采集方式 | 一次一整幅 | 随运动逐行拼接(飞拍) |
| 强项 | 定点/小视场三维、干涉/共聚焦成像 | **大幅面、连续基片、高吞吐、光照均匀** |
| AOI 用途 | 孔位内细节、三维形貌点测 | 144 孔盘/大面积快速扫查、缺陷普查 |
| 与 FPGA 配合 | 硬触发单帧 | **PSO 位置同步逐行触发**(直线电机 + 光栅尺 + FPGA 的最佳用武之地) |

> 线阵相机的行触发正是几十纳秒同步 + 光栅尺 PSO 的核心场景：台子匀速走，FPGA 按光栅尺位置逐行触发，
> 位置与像行严格对齐——这直接决定线阵图像的几何精度与可复现性。二者同装，按配方切换使用。

## 4. 落地步骤(建议顺序，先治本再提精度)

1. **统一控制 + 治理布线**(⑫⑱)：把分散控制收进一台 DAC-3D 控制器，连接器化、屏蔽、线号——先把"乱"和"散"解决。
2. **换直驱台 + 光栅尺**(②③)：消除背隙/传动误差，装 FPGA 硬触发。
3. **装标准件、建标定链**(⑯)：用标准台阶片量化当前重复性，作为改造前后的对照基线。
4. **压电精聚焦 + 色散共聚焦头联调**(④⑤⑦)：跑通三维形貌测量。
5. **隔振 + 恒温 + 预热规范**(⑭⑮)：压住热漂移与振动。
6. **重复性验收**：同一标准台阶，同一天多次 + 多天重复测量，量化 σ；台阶高度示值与真值误差纳入验收。

**验收金标准(务实档目标)**：标准台阶片高度测量，**单日重复性 σ 与多日复现性**达到样机的显著改善(建议目标：
重复性 σ 进入亚百纳米并稳定可溯源)，且线阵扫查图像几何无错位——具体数值待现场基线测定后设定。
