# DAC-3D 显微检测平台硬件方案 —— 迈向世界级微纳三维/生物细胞检测 V1.0

> 场景: 实验室将建 **5–6 套 XYZ 运动显微光学检测仪**，以奥林巴斯 BX 系列显微平台改装，
> XY 行程 110mm×120mm，载物台 285mm×225mm（常载 144 孔盘，装光学元件或生物细胞），
> 置于空气避震台上。
> 十年目标: 在**微纳光学 AOI 三维形貌**与**生物细胞高精检测**两个方向达到世界级。
>
> 本文与 [`dac3d-hw-highavail-timing-design.md`](./dac3d-hw-highavail-timing-design.md)（单站控制器/几十纳秒）
> 与 [`dac3d-product-strategy.md`](./dac3d-product-strategy.md)（视觉同步协处理器战略）配套。

## 0. 先讲三个不讨喜但决定成败的判断

**判断一：世界级纳米三维，胜负手不在相机，在"计量回路"。**
纳米级形貌测量的极限，几乎总是被**振动、热漂移、机械框架刚性**先卡住，而不是被传感器分辨率卡住。
一台再好的干涉仪，装在会漂 50nm/小时的框架上，也测不出可信的 5nm 台阶。所以钱和精力要优先砸在
**隔振 + 热稳定 + 计量框架**，其次才是 Z 精定位与编码器，再次才是光学头，最后才是相机。

**判断二：改装 BX 是绝佳的起点，但不是世界级的终点。**
BX 是优秀的**显微观察**框架，却不是**计量框架**——它的立柱刚性、热稳定、载物台承载都是为"看"而非"nm 级测"设计的。
- 生物细胞检测 + 中等精度 AOI：改装 BX **完全够用**，且性价比极高（Phase 1–2 主力）。
- 世界级纳米三维形貌：BX 框架会在某个精度台阶成为极限，届时需要**花岗岩桥式/专用计量框架**（Phase 3+）。
本方案给出"改装 BX 打底 → 逐步升级计量框架"的平滑路径，而不是一步到位买最贵的。

**判断三：两个方向差异大，但应共用一个平台、可换光学头。**
AOI 三维（亮、快、非接触形貌）与生物细胞（暗、荧光、活体友好）光学需求不同，但
**运动 + 控制 + 同步 + 数据**可以完全共用。做成"**统一运动/控制平台 + 可换光学测量头**"，
正是前述"一套控制器、按配方复用于不同系统"战略在硬件上的落地——5–6 台机同架构，只是头不同。

## 1. 平台总览：统一底盘 + 可换测量头

```
┌───────────────────────────────────────────────────────────────────────┐
│                     每一站 = 统一底盘 + 一个可换光学头                    │
├───────────────────────────────────────────────────────────────────────┤
│  可换光学测量头（按站/按项目选一）                                       │
│   ├ 色散共聚焦头(DAC)  ├ 白光干涉头(WLI/CSI)  ├ 共聚焦头               │
│   ├ 结构光头(DMD-SIM)  └ 数字全息/定量相位头(DHM/QPI, 生物无标记)      │
├───────────────────────────────────────────────────────────────────────┤
│  统一底盘（5–6 台完全一致）                                             │
│   · XY 扫描台（直线电机 + 纳米光栅尺）  · Z 粗动 + 压电精聚焦           │
│   · DAC-3D 控制器（FPGA 几十纳秒同步 + 厂商无关编码器边界）              │
│   · 相机/探测器  · 照明  · 空气避震 + 主动隔振 + 热罩                    │
│   · 统一软件（HAL + 配方 + 算法库 + 数据格式）                          │
└───────────────────────────────────────────────────────────────────────┘
```

> 关键收益：5–6 台**同一套控制器、同一套软件、同一套标定流程**，只按测量头装不同配方。
> 一致性 = 可复现 = 世界级的可信度基础；也让维护、升级、AI 数据汇聚都事半功倍。

## 2. 分系统方案

### 2.1 运动 XYZ（更优方案的第一重点）

BX 原生机械载物台行程仅约 76×52mm，**满足不了 110×120mm**，因此 **XY 台整体替换**，
保留 BX 立柱/光学/照明接口。

| 子项 | 务实档（Phase 1–2，改装 BX） | 世界级档（Phase 3+） |
|------|------------------------------|----------------------|
| XY 台 | 交叉滚柱 + **直线电机**，110×120mm | **气浮**直线电机台，超低直线度/平面度误差 |
| XY 反馈 | **纳米级直线光栅尺**（增量，亚 nm 插值） | 绝对式纳米光栅尺 + 实时误差映射补偿 |
| XY 参考型号 | PI / ACS / 固高高端；Renishaw TONiC 尺 | PI / Aerotech 气浮；Renishaw RESOLUTE 绝对尺 |
| Z 粗动 | 电动调焦（mm 级，找面） | 同左 + 主动漂移补偿 |
| Z 精动 | **压电物镜纳米聚焦**（PIFOC 类，~100μm，闭环电容传感，亚 nm） | 同类 + 更大行程/更高带宽 |
| 承载 | 需承 285×225mm 台 + 144 孔盘质量，校核动态整定时间 | 轻量化高刚性台面，缩短整定 |

要点：
- **XY 用直线电机 + 光栅尺闭环**，而非丝杠 + 旋转编码器——直驱无背隙、直线尺消除传动误差，是 XY 亚微米/纳米可复现的前提。
- **Z 必须两级**：电动粗调找面（mm）+ 压电精扫（亚 nm，闭环电容/应变传感）。纳米三维、共聚焦/干涉的轴向扫描全靠压电这一级。
- 直驱台的编码器/位置信号经我们已建的**厂商无关 `IEncoderSource` 边界**接入 FPGA（正交差分直入），
  换 PI / Aerotech / ACS / 国产台**只改驱动 + 配方，不改核心与 FPGA**——这正是上一步铺路的用途。
- 注意 **Abbe 误差、余弦误差、载物台平面度**：世界级要把光栅尺尽量靠近测量点（缩短 Abbe 臂），并做几何误差标定补偿。

### 2.2 光学测量头（可换，决定"测什么、多准"）

按方向选头，共用底盘：

| 测量头 | 原理/优势 | 最适 | 轴向能力 |
|--------|-----------|------|----------|
| **色散共聚焦 DAC** | 颜色=高度，非接触，快 | 光学元件形貌、台阶、粗糙度 | 亚 μm~nm（依传感） |
| **白光干涉 WLI/CSI** | 相干扫描，纳米级面形金标准 | 光学表面/镀膜三维形貌 | **亚 nm**（强依赖隔振） |
| **激光/转盘共聚焦** | 光学切片，三维堆栈 | 细胞三维、微结构 | ~100nm 级 |
| **结构光 DMD-SIM** | 图样投影，光切 + 超分 2× | 细胞/微结构，兼容既有 DMD | 光切 |
| **数字全息/定量相位 DHM/QPI** | 无标记定量相位，纳米轴向 | 活细胞形态/干重，无染色 | nm 轴向 |

推荐配置（5–6 台分工示例）：
- 2 台 **WLI/CSI + 色散共聚焦**：主攻微纳光学 AOI 三维形貌（世界级面形）。
- 2 台 **共聚焦 + DMD-SIM**：主攻生物细胞三维/结构光，兼容 DMD 细胞切割项目。
- 1–2 台 **DHM/QPI**：活细胞无标记高精检测（差异化、易出顶刊成果）。

> 模块化头 + 统一底盘，意味着某个方向要冲更高精度时，只升级那一台的头，不动整线。

### 2.3 相机 / 探测器

- **AOI 三维/干涉**：高分辨全局快门工业相机（既有 Basler 体系可延续）；干涉头按其专用相机。
- **生物荧光/DHM**：**制冷 sCMOS**（Hamamatsu ORCA / Photometrics / Andor 级），高 QE、低噪声、弱光可用。
- 曝光时刻由 **FPGA 门控照明频闪定义**（见几十纳秒方案），绕开相机内部快门抖动——两类相机通用。

### 2.4 照明

- **AOI**：多角度明/暗场、同轴、RGB（既有穹顶光延续），暗场对划伤/颗粒最敏感。
- **生物**：荧光激发 **LED 光引擎**（Lumencor / CoolLED 类）+ 滤光块转轮；**DMD** 兼作结构光照明 / 图样光刺激 / 细胞切割。
- 所有照明频闪均由 FPGA 门控，做到几十纳秒级曝光定义与多器件对齐。

### 2.5 隔振与环境（世界级的真正门槛）

空气避震台是**必要非充分**。世界级纳米三维还需：
- **主动隔振**（AVI，如 Herzan / TMC 主动台或加装主动模块）：压制低频（1–10Hz）地面振动，被动气浮压不掉的频段。
- **声学 + 气流罩**：nm 级测量对声压和气流敏感，需封闭隔声罩。
- **热稳定 ±0.1℃**：热漂移是 nm 级第一杀手。恒温罩 + 低膨胀材料（殷钢/花岗岩）+ 避开人体/电源热源。
- **计量回路与受力回路分离**：让测量参考框架不承受运动反力（Phase 3+ 花岗岩桥式框架的核心思想）。
- **洁净度**（生物 + 光学表面）：局部层流/洁净罩，减少颗粒污染影响判读。

### 2.6 控制与同步（DAC-3D 控制器，前序工作在此复用）

- **每站一台 DAC-3D 控制器**：FPGA 做相机/DMD/频闪/压电 Z 的**几十纳秒同步**（见对应方案）。
- 高端直驱台经**厂商无关 `IEncoderSource`** 接入——世界级运动台想换谁就换谁，控制逻辑不动。
- 5–6 台控制器**固件/软件完全一致**，按测量头加载不同配方。

## 3. 标准化与可复现（世界级的"可信度"工程）

世界级不只是"某次测得准"，而是"**5–6 台、任何一天、任何一人测都一致且可溯源**"：
- **计量溯源**：配 NIST/国家计量院可溯源的**标准台阶片、平面度标准、荧光标准珠**，每台定期标定并留档。
- **台间一致性**：同一标准件在 5–6 台上互测，量化台间偏差，纳入验收。
- **统一数据格式 + 数据库**（延续既有 database_service）：所有测量带标定链、环境记录、批次可追溯。
- **数据资产 → AI**：统一格式的海量三维/细胞数据，喂给瑕疵检测/形貌重建算法（CFAN 等），形成"越测越强"的算法飞轮。

## 4. 十年四阶段路线

| 阶段 | 周期 | 目标 | 关键动作 |
|------|------|------|----------|
| **P1 打底** | 1–2 年 | 建成 1 台**参考站**并跑通溯源 | 改装 BX + 直线电机台 + 压电 Z + 色散共聚焦/共聚焦；建标定链 |
| **P2 复制** | 2–4 年 | 复制到 5–6 台，台间一致 | 统一底盘/控制器/软件；台间互标；生物 + AOI 双线并行 |
| **P3 冲精度** | 4–7 年 | 纳米三维进世界级第一梯队 | 引入 WLI/CSI + 主动隔振 + 恒温罩 + 花岗岩计量框架升级 |
| **P4 树标杆** | 7–10 年 | 出标准、出顶刊、对标世界名室 | DHM/QPI 无标记活细胞；与国家计量院比对；发布方法与数据集 |

> 每阶段都可交付、可发表、可自证，避免"十年憋大招"的风险。

## 5. 选型清单（示例，分档可裁剪）

| 子系统 | 务实档（P1–2） | 世界级档（P3+） |
|--------|----------------|-----------------|
| XY 台 | 交叉滚柱直线电机台 110×120 | 气浮直线电机台 |
| XY 光栅尺 | Renishaw TONiC（增量，亚 nm 插值） | Renishaw RESOLUTE（绝对） |
| Z 精动 | PI PIFOC 类压电物镜聚焦（闭环电容） | 更大行程/高带宽压电 |
| 光学头 | 色散共聚焦 / 转盘共聚焦 | WLI/CSI + DHM/QPI |
| 相机 | Basler（AOI）/ 入门 sCMOS（生物） | 高端制冷 sCMOS |
| 照明 | RGB 穹顶 + LED 荧光引擎 + DMD | 同左 + 更强激发/更多波段 |
| 隔振 | 空气避震台 | 主动隔振 + 恒温声学罩 |
| 框架 | 改装 BX | 花岗岩桥式计量框架 |
| 控制 | DAC-3D 控制器（每站一台） | 同左（软硬件不变，正是设计目标） |

> 国产替代：P1–2 关键计量件（光栅尺、压电、干涉头）以进口为主保证世界级起点；
> 十年内逐步导入国产替代并做等效性验证——与既有架构文档"国产替代路线"一致。

## 6. 一句话总结

> 用"**统一运动/控制底盘 + 可换光学测量头**"建 5–6 台同架构显微检测仪：AOI 三维与生物细胞
> 共平台、按头分工。世界级的钱先砸在**隔振/热稳定/计量框架**（真正的门槛），再到 Z 压电与纳米光栅尺，
> 再到干涉/共聚焦/定量相位测量头；控制与几十纳秒同步复用 DAC-3D 控制器，高端运动台经厂商无关编码器
> 边界即插即用。改装 BX 打底、逐阶升级计量框架，十年四步：打底 → 复制 → 冲精度 → 树标杆。
